1. ## What is JSX?

JSX is a syntax extension of JAVASCRIPT, JSX means JAVASCRIPT xml, JSX is HTML-like syntax xml-like syntax.
JSX is not javascript/react/HTML , All are diffrent.
If we write code in JSX JS ENGINE/ browser does not understand it.
Parcel bundler does this job for us, parcel is like a manager it gives this reponsibility to BABEL .
BABEL is a Javascript compiler/Traspiler , this will traspile our JSX code to browser understandable code which is JAVASCRIPT/REACT.
JSX make developer life easy.

In JSX we write class attribute of HTML as className, we use camel case to mention attributes.
And we have to close all tags in JSX , JSX is very strcit.

4. ## {TitleComponent()} vs {<TitleComponent/>} vs {<TitleComponent></TitleComponent>} in JSX?

All are same {TitleComponent()} vs {<TitleComponent/>} vs {<TitleComponent></TitleComponent>} , these are 3 different types of Component Composition which means these are the ways to render one functional component inside another component. 5. ## Create a Nested header Element using React.createElement(h1,h2,h3 inside a div with class “title”)

const nested = React.createElement("div",{className:"title"},
                                    React.createElement("h1",{},"Iam H1"),
                                    React.createElement("h2",{},"Iam h2"),
                                    React.createElement("h3",{},"Iam h3")
);

const root = ReactDOM.createRoot(document.getElementById("root"));

root.render(nested);

8. ## Composition of Component(Add a component inside another)

All react functional components starts with capital letter

const Comp1 = () => (
    <div>
        <h1>Iam H1 inside Functional component 1</h1>
        <h2>Iam H2 inside Functional Component 2</h2>
    </div>
);

const Comp2 = function () {
    return (
        <>                   //Fragment wrapper resolves the adjacent elements error if there are adjacent tags to return you have to use <></>
        {Comp1()}
        <div id="comp2">
        <h2>Iam from Functional Component 2</h2>
        </div>
        </>
    );
};

const Comp3 = () => {
    return (<div>
        <Comp2></Comp2>
        <h3>Iam from functional Component 3</h3>
    </div>);
};


const Comp4 = () => <div><Comp3/> <h4>Iam from functional Component 4</h4> </div>

const root = ReactDOM.createRoot(document.getElementById("root"));

root.render(<Comp4 />);
